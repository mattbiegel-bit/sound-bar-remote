Remote setup

Connect a Broadlink RM Mini or RM Pro IR blaster to your Wi-Fi using its app. Place it within sight of the soundbar.

On a computer on the same network, run the included Python bridge and teach it each button with a compatible physical remote. See the project README for the setup commands.

Open the address printed by the bridge to send real commands. This preview simulates the remote.
